# Engineering log

Short, dated notes on what I did, why, and what went wrong. Newest first.

Create a new entry either in Obsidian (new note in `log/` → *Insert template* → `log-entry`)
or from the terminal, which also adds the link below automatically:

```bash
./new-entry.sh "short title"
```

File names: `YYYY-MM-DD-short-title.md`.
